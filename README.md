# Urbanbite – Responsive Restaurant Website

Urbanbite is a modern and responsive restaurant website built using HTML, CSS, and JavaScript.

## Features
- Responsive design for mobile and desktop
- Modern restaurant homepage
- Popular dishes menu with images and prices
- About Us section
- Table booking form with input validation
- Contact information and footer
- Smooth scrolling navigation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Overview
This project was created to practice frontend web development and build a professional restaurant website experience.
